# Amazon UI Redesign

## Project Overview
A modern redesign of the Amazon India shopping homepage, focused on improving visual hierarchy, navigation and user experience.

## Features
- Modern navigation bar
- Product search functionality
- Shopping categories
- Deals of the Day
- Product ratings and pricing
- Add to Cart counter
- Prime promotional section
- Responsive desktop and mobile layouts

## Design Theme
- Navy Blue: `#0F1F44`
- Orange: `#FF9900`
- White: `#FFFFFF`
- Light Grey: `#F5F7FA`

## Technologies Used
- React.js
- Vite
- JavaScript
- CSS3
- Lucide React

## Installation and Setup

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal.
