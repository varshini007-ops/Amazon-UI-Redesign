
# Amazon UI Redesign – Style Guide

## 1. Project Overview
A modern and user-friendly redesign of the Amazon shopping homepage.

## 2. Colour Palette

| Colour | Hex Code | Usage |
|---|---|---|
| Navy Blue | #0F1F44 | Header and Footer |
| Dark Blue | #192D52 | Navigation |
| Orange | #FF9900 | Buttons and Highlights |
| White | #FFFFFF | Cards and Sections |
| Light Grey | #F5F7FA | Page Background |

## 3. Typography
- Primary Font: Arial
- Heading: Bold
- Body Text: Regular
- Buttons: Bold

## 4. UI Components
- Navigation Bar
- Search Bar
- Product Cards
- Category Cards
- Add to Cart Button
- Prime Banner
- Footer

## 5. Design Principles
- Clean visual hierarchy
- Consistent spacing
- Easy navigation
- Clear product presentation
- Responsive layouts

## 6. Responsive Design
- Desktop: Multi-column product layout
- Tablet: Three-column product layout
- Mobile: Two-column product layout
- Small Mobile: Single-column product layout

## 7. Design Theme
Navy Blue + Orange + White

## 8. Tools Used
- React.js
- Vite
- CSS3
- JavaScript
- Lucide React Icons
- VS Code
