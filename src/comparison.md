
# Amazon UI Redesign – Before & After Comparison

## 1. Project Overview
This project redesigns the Amazon India shopping homepage to create a cleaner, more organised and user-friendly shopping experience.

## 2. Before Redesign – Original Website

### Observed Issues
- Crowded navigation bar with many menu options.
- Multiple promotional banners competing for attention.
- Busy visual presentation.
- Product sections have different promotional styles.
- Difficult to identify the main visual focus.

## 3. After Redesign – Updated Website

### Improvements
- Introduced a navy blue, orange and white colour theme.
- Created a simplified navigation bar.
- Added a clear hero section with a shopping message.
- Organised shopping categories into cards.
- Designed consistent product cards.
- Added product ratings, prices and discount labels.
- Included an Add to Cart interaction.
- Added an Amazon Prime promotional section.
- Created a structured footer.
- Added responsive layouts for desktop and mobile screens.

## 4. Before vs After

| Design Element | Before | After |
|---|---|---|
| Navigation | Crowded | Simplified |
| Colour Theme | Multiple colours | Navy, Orange, White |
| Hero Section | Promotional banners | Clear hero section |
| Categories | Mixed promotional layout | Organised cards |
| Products | Busy presentation | Consistent cards |
| Footer | Not part of our redesign focus | Structured footer |
| Responsiveness | Original layout | Responsive CSS |

## 5. Technologies Used
- React.js
- Vite
- JavaScript
- CSS3
- Lucide React

## 6. Final Outcome
The redesigned website provides a more organised shopping interface with improved visual hierarchy, consistent styling and responsive layouts.

## 7. Conclusion
This redesign helped improve my understanding of UI design, visual hierarchy, colour selection, component-based development and responsive web design.
